# Ninaj Awin — GitHub Pages site


> **Institutional attribution:** Ninaj Awin was a multidisciplinary research and educational project of the **Universidad Mayor de San Simón (UMSS)**, Cochabamba, Bolivia, developed in 2015. This repository is a personal historical archive maintained by Eduardo Di Santi; repository ownership should not be confused with ownership of the original university project.

Static retrospective website for the 2015 Ninaj Awin / La Fábrica project at UMSS.

## Publish on GitHub Pages

1. Copy the contents of this directory into the root of `eduardodisanti/ninaj-awin`.
2. Commit and push to the default branch.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then save.

The site is plain HTML/CSS and requires no build step.
